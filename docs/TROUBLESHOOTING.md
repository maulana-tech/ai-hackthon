# 🔧 Troubleshooting Guide

Panduan singkat mengatasi error instalasi dan setup TrendScout AI Agent.

---

## ⚡ Quick Start (Setup dari Nol)

```bash
# 1. Install UV (package manager super cepat!)
curl -LsSf https://astral.sh/uv/install.sh | sh
source ~/.bashrc

# 2. Clone dan masuk directory
cd ~/web/ai-hackthon

# 3. Sync dependencies (30-60 detik, otomatis create .venv!)
uv sync

# 4. Setup environment variables
cp .env.example .env
# Edit .env, isi API keys wajib:
# - GEMINI_API_KEY
# - OPENROUTER_API_KEY
# - GETCIRCLO_JWT_TOKEN
# - FIRECRAWL_API_KEY
# - APIFY_API_KEY

# 5. Install dan setup ngrok
brew install ngrok  # macOS
ngrok config add-authtoken YOUR_TOKEN

# 6. Start services
./start_ngrok.sh

# 7. Test di GetCirclo
# Search: @trendscout-ai
# Send: "Buat kampanye untuk smartwatch"
```

## 🚨 Common Issues

### 1. `ModuleNotFoundError: No module named 'fastapi'`

**Fix:**
```bash
cd ~/web/ai-hackthon
uv sync
uv run uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### 2. `uv: command not found`

**Fix:**
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
source ~/.bashrc  # atau ~/.zshrc
uv --version
```

### 3. `Address already in use` (Port 8000)

**Fix:**
```bash
pkill -f uvicorn
# atau
lsof -i :8000  # lihat PID
kill -9 <PID>
```

### 4. `ngrok: command not found`

**Fix:**
```bash
# macOS
brew install ngrok

# Ubuntu/Linux
curl -s https://ngrok-agent.s3.amazonaws.com/ngrok.asc | \
  sudo tee /etc/apt/trusted.gpg.d/ngrok.asc >/dev/null && \
  echo "deb https://ngrok-agent.s3.amazonaws.com buster main" | \
  sudo tee /etc/apt/sources.list.d/ngrok.list && \
  sudo apt update && sudo apt install ngrok

# Authenticate
ngrok config add-authtoken YOUR_TOKEN
```

### 5. `ERR_NGROK_108: Invalid credentials`

**Fix:**
```bash
# Get token dari https://dashboard.ngrok.com/get-started/your-authtoken
ngrok config add-authtoken YOUR_TOKEN_HERE
ngrok http 8000  # test
```

### 6. GetCirclo timeout (> 30 detik)

**Fix:**
```bash
# Check logs
tail -f logs/server.log

# Test response time
time curl -X POST http://localhost:8000/circlo-webhook/hook \
  -H "Content-Type: application/json" \
  -d '{"message":"test","user":{"id":"1","name":"Test","preferredKeywords":[],"preferredNiches":[]},"profile":{"id":"1","name":"Agent","niche":"Test"},"history":[]}'

# Harus < 30 detik
```

### 7. `GEMINI_API_KEY not found`

**Fix:**
```bash
cp .env.example .env
nano .env  # isi semua API keys
cat .env | grep GEMINI_API_KEY  # verify
```

### 8. Dependencies conflict error

**Fix:**
```bash
rm -rf .venv
uv sync  # UV smart resolver auto-fix conflicts
```

### 9. `ERROR: Could not build wheels for lxml`

**Fix:**
```bash
# macOS
xcode-select --install

# Ubuntu
sudo apt-get install python3-dev libxml2-dev libxslt-dev

# Then
uv sync
```

### 10. Agent registration failed

**Fix:**
```bash
# Verify JWT token
grep GETCIRCLO_JWT_TOKEN .env

# Verify ngrok running
curl -s http://localhost:4040/api/tunnels

# Register
python3 scripts/register_circlo_agent.py
```

## 📚 Essential Commands

### UV Package Management (RECOMMENDED)

```bash
uv sync                    # Install/sync dependencies
uv add <package>           # Add package
uv remove <package>        # Remove package
uv run <command>           # Run in venv (no activate needed!)
uv pip list                # List packages
```

### Running

```bash
# With UV (easiest)
uv run uvicorn app.main:app --host 0.0.0.0 --port 8000

# With script
./start_ngrok.sh

# Stop
./stop_services.sh
```

### Testing

```bash
uv run pytest              # Run all tests
uv run pytest -v tests/    # Verbose
```

### Debugging

```bash
# Logs
tail -f logs/server.log
grep "ERROR" logs/app.log

# Check server health
curl http://localhost:8000/health

# Check ngrok
open http://127.0.0.1:4040
```

### Cleanup

```bash
# Remove cache
find . -type d -name __pycache__ -exec rm -rf {} +
rm -rf .pytest_cache .uv

# Fresh install
rm -rf .venv
uv sync
```

## 🔍 Advanced: Traditional pip (Alternative)

Jika tidak mau pakai UV:

```bash
# Create venv
python3 -m venv .venv
source .venv/bin/activate

# Install
pip install -r requirements.txt

# Run
python3 -m uvicorn app.main:app --host 0.0.0.0 --port 8000

# Deactivate
deactivate
```

**Note:** UV 10-100x lebih cepat dan auto-manage venv!

## 💡 Tips

1. **Selalu gunakan UV** - jauh lebih cepat dari pip
2. **`uv sync`** otomatis create dan manage `.venv`
3. **`uv run`** tidak perlu activate venv manual
4. **Check logs** di `logs/server.log` untuk debug
5. **Ngrok dashboard** di `http://127.0.0.1:4040` untuk monitor requests

## 📞 Still Having Issues?

1. Check logs: `tail -100 logs/app.log`
2. Enable debug: Set `LOG_LEVEL=DEBUG` in `.env`
3. Fresh install: `rm -rf .venv && uv sync`
4. Check [GitHub Issues](https://github.com/your-repo/issues)
