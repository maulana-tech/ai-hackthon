## 📊 Complete Sheets Structure

### Sheet 1: 📊 Overview Dashboard
```
Campaign Overview
Product: [Name]
Total Budget: Rp 5,000,000
Duration: 30 days
Daily Budget: =B3/B4

Quick Stats
Total Spent: =SUM('Daily Tracking'!D:D)
Remaining Budget: =B3-B8
Budget Used %: =B8/B3
Days Elapsed: =COUNTA('Daily Tracking'!A:A)-1
Days Remaining: =B4-B11

Platform Performance
Platform | Budget | Spent | Remaining | ROI
Instagram | 1.75M | =FORMULA | =FORMULA | =FORMULA
(Auto-linked to Daily Tracking)
```

### Sheet 2: 📅 Daily Tracking
```
14 Columns:
1. Date
2. Platform
3. Campaign Type
4. Spent (Rp)
5. Impressions
6. Clicks
7. CTR % (=F2/E2*100)
8. Conversions
9. Conv Rate % (=H2/F2*100)
10. Cost Per Click (=D2/F2)
11. Cost Per Conversion (=D2/H2)
12. Revenue (Rp)
13. ROI % (=(L2-D2)/D2*100)
14. Notes

With Conditional Formatting:
🟢 Green: Good performance
🟡 Yellow: Average
🔴 Red: Below target
```

### Sheet 3: 🚀 Platform Performance
```
13 Columns comparing all platforms:
- Total Budget
- Total Spent (=SUMIF...)
- Remaining
- Budget Used %
- Total Impressions
- Total Clicks
- Avg CTR %
- Total Conversions
- Avg Conv Rate %
- Total Revenue
- Total ROI %
- Status (🟢🟡🔴)

Auto-aggregates from Daily Tracking
```

### Sheet 4: 💰 Budget Tracking (MAIN)
```
4 Sections:

1. Budget Allocation
   Platform | Allocated | % | Daily | Spent | Remaining | Days Used | Projected | Over/Under | Status

2. Weekly Summary
   Week 1-4 with planned vs actual spend

3. Category Breakdown
   Content Creation | Paid Ads | Influencer
   Budget | Spent | Remaining | %

4. Alerts
   Budget Alert: Over 80% spent → ⚠️ WARNING
   Pace Alert: Spending too fast → ⚠️ TOO FAST
   Performance Alert: ROI below target → ⚠️ LOW ROI
```

### Sheet 5: 📈 KPI Dashboard
```
5 Key Metrics:

1. Reach: Target 50,000
2. CTR: Target 2%
3. Conversion Rate: Target 1%
4. ROI: Target 300%
5. Cost Per Conversion: Target Rp 50,000

Each with:
- Current value (=FORMULA from Daily Tracking)
- Progress % towards target
- Status indicator (🟢🟡🔴)
- Trend sparkline
```
