## 🤖 Automation Flow

### Step 1: User Request
```
User: "Buat kampanye marketing untuk smartwatch"
```

### Step 2: AI Generates Campaign
```python
campaign = await marketing_agent.generate_campaign(
    product_name="smartwatch",
    ...
)
```

### Step 3: Document Created
```python
doc_result = await document_service.create_campaign_document(
    campaign_name="smartwatch",
    campaign_data={...}
)
# Returns: http://localhost:8000/documents/408da2a54639/view
```

### Step 4: Auto-Execute Next Steps (Parallel)
```python
automation = await campaign_automation.auto_execute_next_steps(
    campaign_data={...},
    product_name="smartwatch"
)

# Executes 5 steps simultaneously:
# 1. Review & Validation (Gemini) → 2-3s
# 2. Budget Optimization (Qwen) → 3-5s
# 3. Content Calendar (Gemini) → 2-3s
# 4. Tracking Setup (Both) → 2-3s
# 5. Launch Checklist (Gemini) → 1-2s
# Total: ~15 seconds
```

## ⚙️ Configuration for GetCirclo

### Step 1: Set Base URL

Update `.env`:
```bash
# Change from localhost to your deployed URL
APP_BASE_URL=https://your-app-domain.com
```

### Step 2: Deploy Application

**Option A: Heroku**
```bash
heroku create your-app-name
heroku config:set APP_BASE_URL=https://your-app-name.herokuapp.com
git push heroku main
```

**Option B: Fly.io**
```bash
fly launch
fly secrets set APP_BASE_URL=https://your-app.fly.dev
fly deploy
```

**Option C: Railway**
```bash
railway init
railway up
# Set APP_BASE_URL in Railway dashboard
```

### Step 3: Update GetCirclo Webhook

In GetCirclo dashboard:
```
Webhook URL: https://your-app-domain.com/circlo-webhook/hook
```

### Step 4: Test

Send message in GetCirclo:
```
"Buat kampanye marketing untuk produk X"
```

Expected: Document URL will be accessible from anywhere!
